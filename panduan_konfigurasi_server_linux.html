Prasyarat & Lingkungan Server

Topologi Network Server

Kebutuhan Akses Root

Pastikan login sebagai superuser root atau gunakan prefix sudo sebelum menjalankan perintah konfigurasi.

sudo su -

A. LAYANAN JARIKGAN DASAR

1 DHCP Server (isc-dhcp-server)

Port 67/68 UDP

Layanan pengalokasian IP Address secara otomatis kepada komputer client di dalam jaringan lokal.

1. Instalasi Paket: 
apt update && apt install isc-dhcp-server -y
2. Konfigurasi /etc/dhcp/dhcpd.conf: 
subnet 192.168.100.0 netmask 255.255.255.0 {
    range 192.168.100.10 192.168.100.50;
    option domain-name-servers 192.168.100.1;
    option domain-name "yoel.com";
    option routers 192.168.100.1;
    option broadcast-address 192.168.100.255;
    default-lease-time 600;
    max-lease-time 7200;
}
3. Tentukan Interface Interface (/etc/default/isc-dhcp-server): 
INTERFACESv4="eth0"
4. Control & Status: 
systemctl restart isc-dhcp-server
systemctl status isc-dhcp-server

2 DNS Server (BIND9 - domain: yoel.com)

Port 53 UDP/TCP

Penerjemah dari nama domain (yoel.com) menjadi IP Address atau sebaliknya.

1. Instalasi Paket: 
apt install bind9 bind9utils bind9-doc -y
2. Konfigurasi Zone (/etc/bind/named.conf.local): 
zone "yoel.com" {
    type master;
    file "/etc/bind/db.yoel";
};

zone "100.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192";
};
3. Buat File Forward (/etc/bind/db.yoel): 
$TTL    604800
@       IN      SOA     yoel.com. root.yoel.com. (
                              2         ; Serial
                         604800         ; Refresh
                          86400         ; Retry
                        2419200         ; Expire
                         604800 )       ; Negative Cache TTL
;
@       IN      NS      yoel.com.
@       IN      A       192.168.100.1
www     IN      A       192.168.100.1
mail    IN      A       192.168.100.1
@       IN      MX  10  mail.yoel.com.
4. Buat File Reverse (/etc/bind/db.192): 
$TTL    604800
@       IN      SOA     yoel.com. root.yoel.com. (
                              1         ; Serial
                         604800         ; Refresh
                          86400         ; Retry
                        2419200         ; Expire
                         604800 )       ; Negative Cache TTL
;
@       IN      NS      yoel.com.
1       IN      PTR     yoel.com.
5. Restart & Pengujian DNS: 
systemctl restart bind9
nslookup yoel.com
dig yoel.com

3 NTP Server (Chrony)

Port 123 UDP

Sinkronisasi waktu presisi untuk seluruh perangkat client di jaringan local.

1. Instalasi & Edit /etc/chrony/chrony.conf: 
apt install chrony -y

# Tambahkan atau ubah baris berikut pada /etc/chrony/chrony.conf:
allow 192.168.100.0/24
local stratum 10
2. Restart & Verifikasi: 
systemctl restart chrony
chronyc tracking
chronyc sources

4 Proxy Server (Squid)

Port 3128 TCP

Layanan perantara akses web, caching, dan pemfilteran situs web.

1. Instalasi & Edit /etc/squid/squid.conf: 
apt install squid -y

# Tambahkan aturan ACL pada file /etc/squid/squid.conf:
acl lan_local src 192.168.100.0/24
acl situs_blok dstdomain .facebook.com .youtube.com

http_access deny situs_blok
http_access allow lan_local
http_port 3128
2. Control & Restart: 
systemctl restart squid
systemctl status squid

B. LAYANAN WEB & DATA

5 Web Server (Apache2 VirtualHost yoel.com)

Port 80 TCP

Layanan penyedia halaman web interaktif menggunakan HTTP Apache2.

1. Instalasi Apache2 & PHP: 
apt install apache2 php libapache2-mod-php -y
2. VirtualHost /etc/apache2/sites-available/yoel.conf: 
<VirtualHost *:80>
    ServerAdmin admin@yoel.com
    ServerName yoel.com
    ServerAlias www.yoel.com
    DocumentRoot /var/www/yoel
    ErrorLog ${APACHE_LOG_DIR}/error.log
    CustomLog ${APACHE_LOG_DIR}/access.log combined
</VirtualHost>
3. Buat Folder & Halaman Web (/var/www/yoel/index.html): 
mkdir -p /var/www/yoel
echo "<h1>Selamat Datang di Web Server yoel.com - SMKN 9 Kab. Tangerang</h1>" > /var/www/yoel/index.html
chown -R www-data:www-data /var/www/yoel
4. Aktivasi VirtualHost & Restart: 
a2ensite yoel.conf
a2dissite 000-default.conf
systemctl restart apache2

6 Database Server (MariaDB)

Port 3306 TCP

Layanan penyimpanan data terstruktur relasional (RDBMS).

1. Instalasi & Amankan Database: 
apt install mariadb-server mariadb-client -y
mariadb-secure-installation
2. Buat Database & User: 
-- Masuk CLI MariaDB: mariadb -u root -p
CREATE DATABASE db_yoel;
CREATE USER 'yoel_user'@'localhost' IDENTIFIED BY 'Password123!';
GRANT ALL PRIVILEGES ON db_yoel.* TO 'yoel_user'@'localhost';
FLUSH PRIVILEGES;

C. LAYANAN BERBAGI BERKAS

7 Samba (SMB/CIFS Sharing)

Port 139, 445 TCP

Layanan berbagi direktori dan berkas lintas platform antara Linux dan Windows.

1. Instalasi & Buat Directory: 
apt install samba -y
mkdir -p /home/share_yoel
chmod 777 /home/share_yoel
2. Konfigurasi /etc/samba/smb.conf: 
[Data_Yoel]
   path = /home/share_yoel
   browsable = yes
   writable = yes
   guest ok = yes
   read only = no
3. Restart Samba: 
systemctl restart smbd

8 Network File System (NFS)

Port 2049 TCP

Protokol berbagai file antar sistem operasi Unix/Linux berkecepatan tinggi.

1. Instalasi Paket & Edit /etc/exports: 
apt install nfs-kernel-server -y
mkdir -p /mnt/nfs_yoel

# Tambahkan baris di /etc/exports:
/mnt/nfs_yoel 192.168.100.0/24(rw,sync,no_subtree_check)
2. Export Shares & Restart: 
exportfs -a
systemctl restart nfs-kernel-server

9 FTP Server (vsftpd)

Port 20, 21 TCP

File Transfer Protocol aman dan cepat untuk upload/download berkas web server.

1. Instalasi & Edit /etc/vsftpd.conf: 
apt install vsftpd -y

# Aktifkan opsi berikut di /etc/vsftpd.conf:
anonymous_enable=NO
local_enable=YES
write_enable=YES
chroot_local_user=YES
2. Control Service: 
systemctl restart vsftpd

D. KEAMANAN & AKSES REMOTE

10 SSH Remote Access (OpenSSH)

Port 22 TCP

Akses terminal jarak jauh berbasis enkripsi teraman.

1. Instalasi & Hardening /etc/ssh/sshd_config: 
apt install openssh-server -y

# Keamanan dasar: Ubah port default & matikan login root langsung
Port 2222
PermitRootLogin no
2. Restart SSH: 
systemctl restart ssh

11 Firewall UFW (Uncomplicated Firewall)

Security Layer

Sistem pemfilteran lalu lintas jaringan berbasis rule port.

1. Konfigurasi Rules Utama: 
ufw default deny incoming
ufw default allow outgoing
ufw allow 80/tcp
ufw allow 53/udp
ufw allow 2222/tcp
ufw enable
ufw status verbose

12 Fail2ban (Proteksi Brute-Force)

IDS/IPS

Pencegah serangan brute-force dengan cara otomatis memblokir IP penyerang.

1. Instalasi & Konfigurasi /etc/fail2ban/jail.local: 
apt install fail2ban -y

# Buat file /etc/fail2ban/jail.local:
[sshd]
enabled = true
port = 2222
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
bantime = 3600
2. Restart Service: 
systemctl restart fail2ban
fail2ban-client status sshd

E. LAYANAN KOMUNIKASI

13 Mail Server (Postfix & Dovecot)

SMTP 25, IMAP 143

Layanan pengiriman & penerimaan surat elektronik lokal domain yoel.com.

1. Instalasi Paket: 
apt install postfix dovecot-imapd dovecot-pop3d -y
2. Konfigurasi /etc/postfix/main.cf: 
myhostname = mail.yoel.com
mydomain = yoel.com
myorigin = $mydomain
mydestination = $myhostname, yoel.com, localhost.$mydomain, localhost
home_mailbox = Maildir/
3. Restart Postfix & Dovecot: 
systemctl restart postfix dovecot

14 Jabber / XMPP Instant Messaging (Prosody)

Port 5222 TCP

Layanan perpesanan instan real-time lokal domain yoel.com.

1. Instalasi & Edit /etc/prosody/prosody.cfg.lua: 
apt install prosody -y

-- Tambahkan VirtualHost di /etc/prosody/prosody.cfg.lua:
VirtualHost "yoel.com"
2. Buat User Chat & Restart: 
prosodyctl register user1 yoel.com Password123!
systemctl restart prosody
